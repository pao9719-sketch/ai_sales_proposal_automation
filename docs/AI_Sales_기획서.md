## 1. 사업 개요

### 1.1 추진 배경

MS가스는 산업가스 신규 고객사에 대한 기술 영업 과정에서 저장설비 설치 조건 검토, 공사비 산정, 공급단가 결정, 손익 검토 및 제안서 작성 등의 업무를 수행하고 있다.

현재 신규 영업 담당자는 고객사의 공장 도면과 현장 정보를 검토하고, 고압가스 관련 법령 및 기존 공사 견적서를 참고하여 투자비를 산정한다. 이후 엑셀을 이용하여 공급단가와 손익을 반복적으로 계산하고, 내부 승인을 거쳐 신규 고객사에 공급 제안서를 제출한다.

이러한 업무 방식은 담당자 경험에 대한 의존도가 높으며, 유사 신규 영업 건에서도 반복적인 계산과 문서 작성 작업이 발생한다. 이에 생성형 AI와 기존 업무 데이터를 활용하여 **신규 영업 검토에서 공급 제안서 초안 작성까지의 업무를 지원하는 시스템**을 구축하고자 한다.

### 1.2 사업 목적

> 신규 고객사의 산업가스 공급 요청에 대해 기존 견적서, 공장 도면, 관련 법령 및 손익 계산 자료를 활용하여 투자비와 수익성을 신속하게 검토하고, 내부 승인 후 공급 제안서 초안을 자동 생성하는 업무 지원 시스템 구축

세부 목표:

1. 기존 공사 견적서 및 손익 계산 자료의 디지털화·표준화
2. 투자비 산정 및 공급 손익 계산 업무 자동화
3. 신규 영업 건별 수익성 검토 및 승인 프로세스 구축
4. 기존 공급 제안서 양식을 활용한 문서 작성 자동화
5. 향후 RAG 기반 법령 검토 및 공장 도면 분석 기능으로 확장

## 2. 현행 업무 분석(As-Is)

### 2.1 현행 업무 프로세스

고객사 산업가스 공급 요청 → 공장 현장 및 도면 확인 → 설비 투자비 산정 → 엑셀 기반 손익 계산 → 내부 검토 및 승인 → 신규 공급 제안서 작성

### 2.2 주요 문제점

| 구분 | 현행 문제점 | 개선 필요사항 |
|---|---|---|
| 기술 검토 | 법령과 도면을 개별 확인 | 관련 기준 검색 및 검토 지원 |
| 투자비 산정 | 과거 견적서를 수작업으로 참고 | 견적 자료 검색 및 계산 자동화 |
| 손익 분석 | 엑셀에 수치를 반복 입력·조정 | 조건별 손익 자동 계산 |
| 내부 승인 | 조건 조정 및 승인에 시간 소요 | 검토·승인 절차 체계화 |
| 제안서 작성 | 기존 문서를 참고하여 작성 | 표준 양식 기반 자동 생성 |
| 영업정보 보안 | 외부 AI 활용 시 정보 유출 우려 | 비식별화 및 민감정보 보호 |

인터뷰에서는 신규 거래처 유치를 위해 손익 계산 결과가 승인 가능한 수준이 되도록 엑셀 수식을 반복 조정하고, 승인까지 며칠이 소요될 수 있다는 점이 강조되었다.

## 3. 목표 업무 프로세스(To-Be)

1. **신규 영업 프로젝트 등록:** 고객사, 가스 종류, 예상 사용량, 공급 조건 입력
2. **기초 자료 업로드:** 기존 견적서, 공장 도면, 손익 계산 자료 등록
3. **설치 조건 및 투자비 검토:** 기준 자료 확인, 공사 항목과 예상 투자비 산정
4. **손익 시뮬레이션:** 공급단가, 원가, 투자비 변경에 따른 손익 자동 계산
5. **내부 손익 검토 및 승인:** 담당자 검토, 조건 수정 및 승인 처리
6. **공급 제안서 자동 생성:** 승인된 조건으로 표준 제안서 초안 작성

설치 조건 검토에는 전문가 판단이 필요하며, AI가 법적 적합성을 최종 승인하는 대신 관련 근거를 제시하고 담당자가 확인하는 구조로 설계한다.

### 4.2 투자비 산정 기능

기존 공사 견적서를 등록하면 공사 항목, 수량 및 금액을 추출하여 투자비 산정을 지원한다. 검토 항목은 산업가스 저장탱크 및 부대설비, 배관 공사비, 설비 설치 및 시공비, 기타 설비 투자비이다.

과거 견적서의 유사 사례를 검색하여 참고 금액을 제공하고, 담당자가 직접 금액을 수정할 수 있도록 한다. AI는 견적 항목 추출과 유사 사례 추천에 활용하며 **최종 금액 계산은 명확한 산식에 따라 처리**한다.

### 4.3 손익 분석 기능

| 계산 항목 | 산정 방식 예시 |
|---|---|
| 예상 매출액 | 예상 판매량 × 공급단가 |
| 예상 매출원가 | 예상 판매량 × 단위당 공급원가 |
| 예상 매출총이익 | 매출액 − 매출원가 |
| 예상 영업기여이익 | 매출총이익 − 추가 운영비 |
| 투자비 회수기간 | 초기 투자비 ÷ 연간 순현금유입액 |

*상기 계산식은 기획 단계 예시로, 실제 원가 체계와 감가상각, 유지관리비, 운송비, 투자 승인 기준에 맞춰 수정해야 한다.*

공급단가 또는 투자비를 변경하면 결과가 즉시 재계산되도록 구성한다.

### 4.4 공급 제안서 자동 생성

내부 손익 검토 완료 시 승인된 데이터로 신규 고객사 공급 제안서 초안을 생성한다. 실제 양식 확보 후 확정할 구성안:

1. 고객사 및 공급 사업 개요
2. 산업가스 공급 조건
3. 저장설비 설치 및 배관공사 개요
4. 예상 투자비 및 공급단가
5. 공급 조건 및 계약 관련 사항
6. 검토 의견 및 추가 협의사항

민감한 내부 손익 정보가 외부 제안서에 노출되지 않도록 내부 검토 문서와 외부 제출용 문서를 분리한다.

## 5. 데이터 구성 및 관리 계획

### 5.1 입력 데이터 정의

| 데이터 유형 | 파일 형식(예상) | 주요 항목 | 용도 |
|---|---|---|---|
| 기존 공급 제안서 | Excel, PDF, HWP | 공급 조건, 제안 항목 | 제안서 자동 생성 |
| 공사 견적서 | Excel, PDF | 공사 항목, 수량, 단가 | 투자비 산정 |
| 공장 도면 | PDF, 이미지, CAD | 건물 배치, 거리, 설비 위치 | 설치 검토 |
| 손익 계산서 | Excel | 매출, 원가, 투자비, 손익 | 손익 시뮬레이션 |
| 관련 법령 | 법령 원문, PDF 등 | 설치 기준, 안전거리 등 | RAG 기반 법령 검색 |
| ERP 데이터 | Excel | 판매량, 매출, 품목, 단가 | 향후 실적 분석 확장 |

### 5.2 데이터 처리 원칙

구형 ERP의 API 연동이 어렵다는 인터뷰 의견에 따라 초기에는 엑셀 다운로드 후 업로드 방식을 사용한다. 기존 견적서와 손익 계산서의 계산 결과를 기준으로 AI 추출 결과를 검증한다.

- 원본 파일은 내부 시스템에서 처리
- 민감정보 분류 후 외부 AI 전송 제한
- 원가·판매단가·손익은 가능한 한 내부 계산 로직으로 처리
- 저장 여부와 보관 기간은 기업 보안 정책에 따라 결정
- 계산 근거와 담당자 수정 내역 확인 가능하도록 구성

## 6. 시스템 아키텍처 제안

```text
사용자 웹 인터페이스
  ├─ 신규 영업 등록 / 데이터 업로드
  ├─ 투자비 산정 / 손익 분석 / 승인
  └─ 공급 제안서 생성
            │
            ▼
     데이터 처리 및 검증
  ├─ Excel/PDF 파싱
  ├─ 투자비·손익 계산 엔진
  ├─ 민감정보 마스킹
  └─ AI 문서 분석·초안 생성
            │
            ▼
  손익 검토서 / 시뮬레이션 / 제안서 초안
```

### 6.1 권장 기술 스택

| 구분 | 제안 기술 | 선정 이유 |
|---|---|---|
| 개발 도구 | Claude Code | 자연어 기반 바이브 코딩 |
| 화면 | Streamlit | 비개발자의 웹앱 MVP 구축에 용이 |
| 백엔드 | Python | 엑셀·PDF 처리 및 계산 로직 |
| 데이터 처리 | Pandas, OpenPyXL | 기존 손익 계산 엑셀 활용 |
| 문서 생성 | python-docx, OpenPyXL | Word·Excel 결과물 생성 |
| AI 모델 | Claude API | 문서 분석 및 제안서 초안 생성 |
| 데이터 저장 | SQLite 또는 파일 기반 | 초기 단일 PC 운영 가정 |
| RAG 확장 | BM25 및 벡터 검색 | 관련 법령 검색과 근거 제시 |

초기에는 Python과 Streamlit으로 MVP를 구축하고, 향후 다수 영업사원 공동 사용이나 복잡한 승인 절차가 필요해지면 Next.js 기반 화면 및 별도 백엔드 전환을 검토한다. 도면 분석은 별도의 기술 검증 과제로 운영한다.

교육 종료 시 목표 산출물은 실행 가능한 웹앱 MVP, 손익 분석 기능, 승인 상태 처리, 제안서 초안 생성, 실행 가이드 및 교육 결과보고서이다. 상용 시스템 완성이나 법령·도면 자동 판단을 보장하지 않으며, 실제 사례 기반 기능 검증을 우선한다.

## 12. 최종 제안

1. **투자비 및 손익 계산 자동화:** 기존 계산식을 재사용하여 손익 검토 시간을 단축하고 일관성을 높인다.
2. **신규 영업 검토 및 승인 절차 체계화:** 조건별 시뮬레이션과 내부 검토 결과를 한 화면에서 관리한다.
3. **공급 제안서 초안 자동 생성:** 승인된 투자비 및 공급 조건으로 신규 고객사 제안서 작성을 지원한다.

본 프로젝트는 단순한 생성형 AI 챗봇이 아닌 **신규 영업 담당자의 실제 업무 프로세스를 개선하는 AI 기반 영업 업무 지원 시스템**을 목표로 한다. 초기에는 수익성 검토 및 제안서 생성에 집중하고, 이후 법령 RAG, 도면 분석, 영업 데이터 통합으로 발전시키는 단계적 접근이 적절하다.

다음 단계는 실제 견적서·손익 계산서·공급 제안서를 기준으로 상세 요구사항 정의서(SRS), 화면 설계서, 데이터 구조 및 개발 작업명세를 확정하는 것이다.
