# AI 신규 영업 제안 및 손익 검토 자동화 (MVP)

`docs/AI_Sales_기획서.md`의 1단계 범위를 구현한 Streamlit 앱입니다.

## 실행

```powershell
pip install -r requirements.txt
streamlit run app.py
pytest            # 계산·마스킹·견적 추출·제안서 보안 테스트
```

제안서 '검토 의견' AI 초안을 쓰려면 환경변수 `ANTHROPIC_API_KEY`를 설정하세요. 없으면 기본 문안으로 대체됩니다.

## 기능 (기획서 ID)

| ID | 구현 위치 |
|---|---|
| F-01 영업 건 관리 | 사이드바 + `core/db.py` |
| F-02 자료 업로드 | 탭 2 (`data/uploads/<건ID>/`) |
| F-03 투자비 산정 | 탭 3, `core/excel_io.py`(견적서 추출), `core/calc.py` |
| F-04 손익 분석 | 탭 4, `core/calc.py` |
| F-05 시뮬레이션 | 탭 5 (공급단가×투자비 격자) |
| F-06 검토·승인 | 탭 6 (작성중→검토요청→승인/반려, 변경 이력, 승인 스냅샷) |
| F-07 제안서 생성 | 탭 7, `core/proposal.py` (외부 제안서 / 내부 검토서 분리) |
| F-10 보안 처리 | `core/masking.py`, AI에는 가명·금액 제외 정보만 전송 |

F-08(법령 RAG), F-09(도면 분석)는 기획서상 2단계 확장 기능이라 포함하지 않았습니다.

## 실제 도입 전 확인할 것

- 손익 산식(`core/calc.py`)은 기획서의 예시 산식입니다. 실제 손익 계산 엑셀의 감가상각·운송비 등 규칙에 맞춰 수정하고, 기존 엑셀 결과와 대조하세요.
- 승인 기준(회수기간·이익률)은 사이드바 기본값이며 회사 정책값이 아닙니다.
- 제안서 양식은 임의 구성(기획서 4.4)입니다. 실제 제안서 샘플 확보 후 `core/proposal.py`를 맞추세요.
- 사용자 인증/권한 관리는 없습니다(단일 PC, 담당자명 자가 입력).
